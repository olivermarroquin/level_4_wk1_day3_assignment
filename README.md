# Day 3 Assignment — Simple Bank App

## What it does

It stores a single account in a dictionary and lets you:

- Deposit money
- Withdraw money (rejects invalid amounts and insufficient funds)
- View your current balance
- View a list of all transactions
- Exit the program

The program runs in a loop showing a menu until you choose to exit.

## How to run

```bash
python3 day_3_assignment.py
```
